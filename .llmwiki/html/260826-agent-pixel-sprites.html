How these were built: the round silhouette is generated from a distance formula (not hand-placed pixel by pixel) so the edge stays clean and symmetric; only the eyes, mouth, cheeks, and item icon above the head are placed by hand. Each item icon (cloud / terminal window / notebook) went through a few redraws — a gear icon read as a diamond, an open-book icon read as a torn card, both undetectable until actually rendered and checked at real size.
