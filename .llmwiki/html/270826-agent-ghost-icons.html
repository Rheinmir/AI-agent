How the symmetry is guaranteed, not just checked: the generator only ever computes the left half of the shape (dome curve, ear nub, eye, one side of each foot) and writes every pixel twice — once at x, once at mirror_x = width - 1 - x — via a single put_mirrored() call. There's no code path that can place a left-side pixel without its right-side twin, which is what the reference screenshot's build was missing.
